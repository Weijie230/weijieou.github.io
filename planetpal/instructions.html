PlanetPal Instructions

Features

PlanetPal teaches users about planets with a dynamic menu, educational text, images, and speech.

How to Use

Select a planet from the menu. The app will show the planet name, image, and description. Click the Speak Description button to hear the description.

Installation

Open the app in a browser that supports PWAs. Click the install icon or choose Install App from the browser menu.

Offline Use

The service worker stores the main app files so the app can still open without internet after the first visit.

Programmer Documentation

To add a new planet, open data.json and add another object inside the planets array.

{
  "title": "Mars",
  "description": "Mars is called the Red Planet.",
  "image": "images/mars.jpg"
}

Make sure each object has a title, description, and image field.
